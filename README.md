# ⚡ DevToolkit Studio — Eines Web i SEO d'Alt Trànsit per a Google AdSense

**DevToolkit Studio** és una suite d'aplicacions web ràpides i gratuïtes dissenyada específicament per a desenvolupadors web, dissenyadors UI/UX i especialistes en SEO. Execució 100% *client-side* en local, sense transmissió de codi confidencial a servidors aliens.

---

## 🧰 Eines incloses:
1. **Validador i Formatejador JSON**: Validació de sintaxi en temps real, minificador, comptador de bytes i còpia ràpida.
2. **Generador CSS de Glassmorphism i Ombres**: Panell interactiu amb previsualització viva i codi CSS llest per copiar.
3. **Generador de Targetes Socials Open Graph i Meta Tags SEO**: Simulador per a Google, Twitter/X, WhatsApp i LinkedIn.
4. **Base64 & URL Encoder / Decoder**: Codificació i descodificació amb suport complet per a caràcters UTF-8, emojis i mode URL-safe.
5. **Regex Tester en Temps Real**: Avaluador d'expressions regulars amb destacat en viu, patrons habituals (email, url, ipv4, dates, colors hex) i desglossament de grups de captura.
6. **Generador de UUID v4 Criptogràfic**: Generació per lots (1 a 50) amb entropia màxima (`window.crypto`), múltiples formats (JSON, cometes, sense guions) i descàrrega en `.txt`.
7. **Generador de Contrasenyes Segures**: Algorisme basat en `window.crypto` amb avaluació militar de robustesa en viu.
8. **Comprovador de Contrast WCAG 2.1**: Avaluació oficial d'accessibilitat AA i AAA segons les directrius W3C.

---

## 🚀 Novetats Clau:
- **Command-Palette estil Raycast / Cmd+K (`Ctrl+K`)**: Cercador instantani d'eines accessible des de qualsevol pantalla amb navegació per teclat (fletxes, enter, esc).
- **Dades Estructurades Schema.org**: Etiquetes JSON-LD oficials `SoftwareApplication` per optimitzar el posicionament SEO orgànic a Google.
- **Rendiment Màxim**: Sense dependències pesades de backend; temps de resposta immediat.

---

## 💎 Monetització amb Google AdSense
1. **Audiència Tècnica d'Alt Valor (B2B)**: CPCs elevats en campanyes de Cloud Hosting (Google Cloud, AWS, Vercel), eines SaaS de desenvolupament i ciberseguretat.
2. **Alta Recurrència (Bookmarks)**: Els desenvolupadors utilitzen eines com JSON, Base64 o Regex de forma continuada en la seva jornada laboral.
3. **Temps de Permanència Elevat**: Interacció activa amb els editors de codi i panells de control, optimitzant les mètriques d'*Active View* d'AdSense.
