# ⚡ DevToolkit Studio — Herramientas Web y SEO de Alto Tráfico para Google AdSense

**DevToolkit Studio** es una suite de aplicaciones web rápidas y gratuitas diseñada específicamente para desarrolladores web, diseñadores UI/UX y especialistas en SEO. Ejecución 100% *client-side* en local, sin transmisión de código confidencial a servidores externos.

---

## 🧰 Herramientas incluidas:
1. **Validador y Formateador JSON**: Validación de sintaxis en tiempo real, minificador, contador de bytes y copia rápida.
2. **Generador CSS de Glassmorphism y Sombras**: Panel interactivo con previsualización en vivo y código CSS listo para copiar.
3. **Generador de Tarjetas Sociales Open Graph y Meta Tags SEO**: Simulador para Google, Twitter/X, WhatsApp y LinkedIn.
4. **Base64 & URL Encoder / Decoder**: Codificación y decodificación con soporte completo para caracteres UTF-8, emojis y modo URL-safe.
5. **Regex Tester en Tiempo Real**: Evaluador de expresiones regulares con resaltado en vivo, patrones habituales (email, url, ipv4, fechas, colores hex) y desglose de grupos de captura.
6. **Generador de UUID v4 Criptográfico**: Generación por lotes (1 a 50) con entropía máxima (`window.crypto`), múltiples formatos (JSON, comillas, sin guiones) y descarga en `.txt`.
7. **Generador de Contraseñas Seguras**: Algoritmo basado en `window.crypto` con evaluación militar de robustez en vivo.
8. **Comprobador de Contraste WCAG 2.1**: Evaluación oficial de accesibilidad AA y AAA según las directrices W3C.

---

## 🚀 Novedades Clave:
- **Command-Palette estilo Raycast / Cmd+K (`Ctrl+K`)**: Buscador instantáneo de herramientas accesible desde cualquier pantalla con navegación por teclado (flechas, enter, esc).
- **Datos Estructurados Schema.org**: Etiquetas JSON-LD oficiales `SoftwareApplication` para optimizar el posicionamiento SEO orgánico en Google.
- **Rendimiento Máximo**: Sin dependencias pesadas de backend; tiempo de respuesta inmediato.
